# Web-Scrcpy 使用说明

## 项目简介

Web-Scrcpy 是一个基于Web的Android屏幕镜像工具,支持局域网内的多客户端同时访问设备屏幕。

## 核心功能

1. **实时投屏**: 将Android设备屏幕实时镜像到Web浏览器
2. **多客户端支持**: 最多支持2台客户端同时访问
3. **远程控制**: 支持触摸、Home、Back、Menu等操作
4. **权限管理**: 管理员可以锁定设备,防止其他客户端操作

## 连接逻辑

### 主服务机器 (localhost/127.0.0.1)
- **自动连接**: 访问页面后自动开始接收视频流
- **管理员权限**: 第一个连接的客户端自动获得管理员权限
- **无需操作**: 页面加载后立即显示设备屏幕

### 局域网客户端 (如 192.168.x.x)
- **手动连接**: 访问页面后显示"等待连接"状态
- **需点击按钮**: 需要点击"连接视频"按钮才能开始观看
- **受限操作**: 只有管理员未锁定设备时才能操作

## 快速开始

### 1. 环境准备
确保已安装Python 3.6+和依赖库:
```bash
pip install -r requirements.txt
```

### 2. 连接Android设备
- 启用USB调试模式
- 使用USB线连接设备到电脑
- 确认设备已通过 `adb devices` 命令识别

### 3. 启动服务
```bash
# 使用默认端口 5001
python app.py

# 或指定端口
python app.py --port 5001
```

### 4. 访问Web界面
- 主服务机器: http://localhost:5001/
- 局域网其他设备: http://<服务器IP>:5001/

## 视频参数优化

当前配置已针对低延迟优化:
- 视频比特率: 8Mbps
- 帧率: 60fps
- 刷新时间: 0ms (无缓冲延迟)
- 自动清空缓冲区: 启用

## 管理功能

### 管理员面板
- **锁定/解锁设备**: 防止其他客户端操作设备
- **查看客户端列表**: 查看所有连接的客户端
- **断开客户端**: 强制断开指定的客户端

### 客户端面板
- **连接视频**: 点击开始接收视频流
- **停止观看**: 停止接收视频流,释放资源

## 常见问题

### 主服务机器黑屏
- 检查服务是否正常启动
- 确认设备已连接并授权
- 查看浏览器控制台是否有错误

### 视频延迟较高
- 确认网络连接稳定
- 关闭其他占用带宽的应用
- 检查视频比特率设置

### 无法连接设备
- 确认USB调试已启用
- 尝试重新插拔USB线
- 检查ADB驱动是否正常安装

## 文件结构

```
web-scrcpy/
├── app.py              # 主服务器程序
├── scrcpy.py           # Scrcpy核心功能
├── scrcpy-server       # Android服务端程序
├── templates/
│   └── index.html      # Web界面
├── static/             # 静态资源(JS/CSS/图标)
├── requirements.txt    # Python依赖
└── start.bat           # Windows启动脚本
```

## 技术栈

- **后端**: Flask + Flask-SocketIO
- **前端**: 原生HTML/JavaScript + JMuxer (视频解码)
- **通信**: WebSocket (Socket.IO)
- **视频**: H.264编码

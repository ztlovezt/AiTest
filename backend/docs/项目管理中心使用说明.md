## 1. 功能概述

项目管理中心是 TestHub 平台的核心模块，用于统一管理平台内的所有测试项目。

### 1.1 支持的测试模块类型

| 模块类型    | 说明                    |
| ------- | --------------------- |
| AI 用例生成 | AI 智能生成测试用例           |
| API 测试  | HTTP/WebSocket 接口测试   |
| UI 自动化  | Web UI 自动化测试          |
| APP 自动化 | Android/iOS APP 自动化测试 |

### 1.2 核心功能

- **统一入口**：在一个地方管理所有测试项目
- **模块整合**：支持同时创建多种类型的测试项目
- **配置同步**：一次修改，自动同步到所有关联子项目
- **快速跳转**：一键跳转到具体测试模块

## 2. 进入项目管理中心

1. 登录 TestHub 平台
2. 在首页找到**配置中心**卡片
3. 点击**配置中心**
4. 进入**项目管理中心**

或者直接访问：`/configuration/project-center`

***

## 3. 创建新项目

### 3.1 操作步骤

1. 进入项目管理中心
2. 点击右上角**创建项目**按钮
3. 填写项目基本信息
4. 选择需要的测试模块类型
5. 配置各模块参数（如需要）
6. 点击**确认创建**

### 3.2 填写项目信息

| 字段   | 说明      | 必填       |
| ---- | ------- | -------- |
| 项目名称 | 项目的显示名称 | 是        |
| 项目描述 | 项目的详细说明 | 否        |
| 项目状态 | 项目的当前状态 | 是（默认未开始） |

### 3.3 选择模块类型

创建项目时，可以选择一种或多种测试模块类型：

- **AI 用例生成**：用于 AI 智能生成测试用例
- **API 测试**：用于 HTTP/WebSocket 接口测试
- **UI 自动化**：用于 Web UI 自动化测试
- **APP 自动化**：用于移动端 APP 自动化测试

### 3.4 配置模块参数

根据选择的模块类型，可能需要配置以下参数：

#### API 测试模块配置

| 参数   | 说明               |
| ---- | ---------------- |
| 项目类型 | HTTP 或 WebSocket |
| 负责人  | 项目负责人            |
| 成员   | 项目成员列表           |
| 开始日期 | 项目开始时间           |
| 结束日期 | 项目结束时间           |

#### UI 自动化模块配置

| 参数     | 说明                      |
| ------ | ----------------------- |
| 基础 URL | 被测网站地址                  |
| 浏览器    | Chrome / Firefox / Edge |
| 无头模式   | 是否隐藏浏览器窗口               |
| 视口宽度   | 浏览器窗口宽度                 |
| 视口高度   | 浏览器窗口高度                 |

#### APP 自动化模块配置

| 参数           | 说明            |
| ------------ | ------------- |
| 平台           | Android / iOS |
| 设备 ID        | 设备标识符         |
| APP 包名       | 被测应用包名        |
| APP Activity | 启动 Activity   |

## 4. 查看项目列表

### 4.1 列表展示内容

项目列表展示以下信息：

| 列名   | 说明           |
| ---- | ------------ |
| 项目名称 | 项目名称，点击可进入详情 |
| 状态   | 项目的当前状态标签    |
| 负责人  | 项目负责人        |
| 模块数量 | 关联的测试模块数量    |
| 创建时间 | 项目创建时间       |
| 操作   | 编辑、删除等操作按钮   |

### 4.2 筛选和搜索

- **状态筛选**：按项目状态（未开始/进行中/暂停/已完成/已归档）筛选
- **搜索**：输入项目名称或描述关键词搜索

### 4.3 统计数据

列表上方展示统计数据卡片：

- 项目总数
- AI 用例生成项目数
- API 测试项目数
- UI 自动化项目数
- APP 自动化项目数

***

## 5. 查看项目详情

### 5.1 进入详情页

点击项目列表中的项目名称，即可进入项目详情页。

### 5.2 详情页内容

| 区域   | 说明                  |
| ---- | ------------------- |
| 基本信息 | 项目名称、描述、状态、负责人等     |
| 关联模块 | 显示所有关联的测试模块         |
| 模块统计 | 各模块的统计数据（如用例数、接口数等） |

### 5.3 关联模块信息

每个关联模块显示：

- 模块类型图标
- 模块类型名称
- 关联的子项目名称
- 模块统计数据
- 跳转按钮

***

## 6. 编辑项目

### 6.1 编辑基本信息

1. 进入项目详情页
2. 点击右上角**编辑**按钮
3. 修改项目名称、描述、状态
4. 点击**保存**

**注意**：修改项目基本信息后，系统会自动同步到所有关联的子项目。

### 6.2 管理项目模块

在详情页可以：

- **添加新模块**：点击添加按钮，选择模块类型并配置
- **编辑模块配置**：点击模块卡片上的编辑按钮
- **移除模块**：点击模块卡片上的删除按钮

***

## 7. 删除项目

### 7.1 操作步骤

1. 在项目列表中，找到要删除的项目
2. 点击操作列的**删除**按钮
3. 在弹出的确认对话框中点击**确认**

### 7.2 删除影响

删除项目会同时删除：

- 项目本身
- 所有关联的模块记录
- 所有关联的子项目（包括子项目下的所有数据）

**请谨慎操作，删除后数据无法恢复。**

***

## 8. 模块跳转

### 8.1 功能说明

从项目管理中心可以快速跳转到各测试模块的具体页面。

### 8.2 跳转方式

在项目详情页，点击关联模块卡片上的**跳转按钮**：

| 模块类型    | 跳转到              |
| ------- | ---------------- |
| AI 用例生成 | AI 用例生成模块的对应项目页面 |
| API 测试  | API 测试模块的对应项目页面  |
| UI 自动化  | UI 自动化模块的对应项目页面  |
| APP 自动化 | APP 自动化模块的对应项目页面 |

### 8.3 跳转后效果

跳转后页面会自动筛选并显示对应的项目数据，方便您直接在该模块进行具体操作。

## 10. 常见问题

### Q1: 创建项目时提示"请选择至少一个模块类型"

**A**: 创建项目时必须选择至少一种测试模块类型。请在创建表单中勾选至少一个模块类型（AI/API/UI/APP）。

### Q2: 修改项目名称后，子项目名称会同步吗？

**A**: 是的，修改项目管理中心的项目名称后，系统会自动同步更新所有关联子项目的名称。

### Q3: 可以只删除某个模块而不删除整个项目吗？

**A**: 可以。在项目详情页，点击对应模块卡片上的删除按钮，可以单独移除该模块。但该操作会同时删除该模块下的所有数据。

### Q4: 一个项目可以同时包含多种测试模块吗？

**A**: 可以。在创建项目时，选择多个模块类型（如同时选择 API 测试 + UI 自动化），项目会同时关联这些模块。

### Q5: 删除项目后可以恢复吗？

**A**: 不可以。删除操作会同时删除项目及其所有关联数据，且不可恢复。请在删除前确认。

### Q6: 非项目负责人可以编辑项目吗？

**A**: 只有项目负责人（owner）和管理员角色的成员可以编辑项目。

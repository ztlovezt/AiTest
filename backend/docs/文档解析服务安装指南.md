## Apache Tika Server 安装

### 1. 下载 Tika Server

从 Apache Tika 官方网站下载最新版本的 Tika Server JAR 文件：

- 官方下载地址：https://tika.apache.org/download.html
- 直接下载：[**tika-server-standard-3.3.0.jar**](https://dlcdn.apache.org/tika/3.3.0/tika-server-standard-3.3.0.jar)

### 2. 放置文件

将下载的 `tika-server-standard-3.3.0.jar` 文件重命名为 `tika-server.jar`，并放置到项目目录：

```
testhub_platform/
└── expand/
    └── doc_analysis/
        └── tika-server.jar
```

### 3. 环境要求

- **Java 17+** 运行环境
- 内存建议：512MB 以上，根据实际情况做调整

验证 Java 环境：
```bash
java -version
```

## Tesseract OCR 安装

Tesseract 是开源的 OCR（光学字符识别）引擎，用于识别图片中的文字。

### 官方安装文档

详细安装说明请参考官方文档：https://tesseract-ocr.github.io/tessdoc/Installation.html

---

### Windows 安装

#### 方法一：使用安装程序（推荐）

1. **下载安装程序**

   访问 UB Mannheim 的 Tesseract 发行版页面：
   https://github.com/UB-Mannheim/tesseract/wiki

   下载最新版本的 Windows 安装程序，例如：

   - `tesseract-ocr-w64-setup-5.5.0.20241111.exe`（64位）

2. **运行安装程序**

   双击运行下载的安装程序。

3. **关键安装选项** ⚠️

   在安装过程中，请务必注意以下选项：

   | 选项 | 说明 | 必须 |
   |------|------|------|
   | **Additional language data** | 额外语言数据 | ✅ 必须勾选 |
   | **Chinese (Simplified)** | 简体中文语言包 | ✅ 必须勾选 |
   | **Add Tesseract to the PATH** | 添加到系统环境变量 | ✅ 必须勾选 |

   ![安装选项示意](https://tesseract-ocr.github.io/tessdoc/images/installer_language_selection.png)

4. **验证安装**

   打开新的命令提示符窗口，执行：
   ```cmd
   tesseract --version
   ```

   检查中文语言包是否安装：
   ```cmd
   tesseract --list-langs
   ```

   输出应包含 `chi_sim`（简体中文）：
   ```
   List of available languages in "C:\Program Files\Tesseract-OCR\tessdata" (6):
   chi_sim
   chi_tra
   eng
   osd
   equ
   normal
   ```

#### 方法二：使用 Chocolatey

如果已安装 Chocolatey，可以执行：

```powershell
choco install tesseract -y
choco install tesseract-language-chi-sim -y
```

### macOS 安装

#### 使用 Homebrew（推荐）

1. **安装 Tesseract**

   ```bash
   brew install tesseract
   ```

2. **安装中文语言包**

   ```bash
   brew install tesseract-lang
   ```

   或者单独安装中文语言包：
   ```bash
   # 简体中文
   brew install tesseract-lang
   # 或手动下载语言包到 tessdata 目录
   cd /usr/local/Cellar/tesseract/<version>/share/tessdata/
   wget https://github.com/tesseract-ocr/tessdata/raw/main/chi_sim.traineddata
   ```

3. **验证安装**

   ```bash
   tesseract --version
   tesseract --list-langs
   ```

### Linux 安装

#### Ubuntu/Debian

```bash
# 安装 Tesseract
sudo apt-get update
sudo apt-get install -y tesseract-ocr

# 安装中文语言包
sudo apt-get install -y tesseract-ocr-chi-sim

# 验证安装
tesseract --version
tesseract --list-langs
```

#### CentOS/RHEL

```bash
# 安装 EPEL 仓库
sudo yum install -y epel-release

# 安装 Tesseract
sudo yum install -y tesseract

# 安装中文语言包
sudo yum install -y tesseract-langpack-chi_sim

# 验证安装
tesseract --version
tesseract --list-langs
```

#### Fedora

```bash
# 安装 Tesseract
sudo dnf install -y tesseract

# 安装中文语言包
sudo dnf install -y tesseract-langpack-chi_sim

# 验证安装
tesseract --version
tesseract --list-langs
```

#### Arch Linux

```bash
# 安装 Tesseract
sudo pacman -S tesseract

# 安装中文语言包
sudo pacman -S tesseract-data-chi_sim

# 验证安装
tesseract --version
tesseract --list-langs
```

## 配置说明

### config.yaml 配置

编辑项目根目录下的 `config.yaml` 文件：

```yaml
server:
  # 文档解析服务URL
  doc_parser_url: "http://localhost:9987"
  # 文档解析语言（简体中文：chi_sim、英文：eng、繁体中文：chi_tra）
  doc_language: "chi_sim"
```

### 配置项说明

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `doc_parser_url` | Tika Server 服务地址 | `http://localhost:9987` |
| `doc_language` | OCR 识别语言 | `chi_sim`（简体中文） |

### 支持的语言代码

| 语言 | 代码 |
|------|------|
| 简体中文 | `chi_sim` |
| 繁体中文 | `chi_tra` |
| 英文 | `eng` |
| 日文 | `jpn` |
| 韩文 | `kor` |

## 启动服务

### Windows

```batch
cd backend
start_doc.bat
```

### macOS / Linux

```bash
cd backend
chmod +x start_doc.sh  # 首次需要添加执行权限
./start_doc.sh
```

### 后台运行（Linux/macOS）

```bash
nohup ./start_doc.sh > tika.log 2>&1 &
```

## 验证安装

### 1. 验证 Tika Server

访问 Tika Server 健康检查端点：

```bash
curl http://localhost:9987/tika
```

正常响应：
```
This is Tika Server. Please PUT a file to /tika to extract text.
```

### 2. 验证 OCR 功能

创建一个包含中文文字的测试图片，然后使用 Tika 提取：

```bash
curl -X PUT -H "X-Tika-OCRLanguage: chi_sim" \
  --data-binary @test_image.png \
  http://localhost:9987/tika
```

### 3. 在 TestHub 中验证

1. 登录 TestHub 平台
2. 进入"需求分析"模块
3. 上传图片、 PDF 或 Word 等需求文档
4. 检查提取的文本是否包含图片中的中文内容

## 常见问题

### 1. Tika Server 无法启动

**问题**：运行 `start_doc.bat` 或 `start_doc.sh` 时报错

**解决方案**：
- 检查 Java 是否正确安装：`java -version`
- 检查 `tika-server.jar` 文件是否存在
- 检查端口 9987 是否被占用

```bash
# Windows 检查端口
netstat -ano | findstr :9987

# Linux/macOS 检查端口
lsof -i :9987
```

### 2. OCR 无法识别中文

**问题**：图片中的中文无法识别或显示乱码

**解决方案**：
- 确认已安装中文语言包：`tesseract --list-langs`
- 确认输出中包含 `chi_sim`
- 检查 `config.yaml` 中的 `doc_language` 配置是否正确

### 3. Tesseract 命令找不到

**问题**：执行 `tesseract --version` 时提示命令不存在

**解决方案**：
- Windows：确认安装时勾选了 "Add Tesseract to the PATH"，如果没有勾选项，安装后手动添加到环境变量
- Linux/macOS：确认 Tesseract 安装路径在 PATH 环境变量中

```bash
# 查找 Tesseract 安装路径
which tesseract  # Linux/macOS
where tesseract  # Windows
```

### 4. 内存不足

**问题**：处理大文件时 Tika Server 崩溃

**解决方案**：
- 增加启动脚本中的内存参数：
  ```bash
  java -Xmx1024m -jar tika-server.jar --host=localhost --port=9987
  ```

### 5. OCR 识别准确率低

**解决方案**：
- 确保图片清晰度足够（建议 300 DPI 以上）
- 尝试不同的 OCR 语言模式
- 对于特殊字体，可能需要训练自定义语言模型
